RuggedizedWrist

Two distal degrees of freedom for contact-rich tool reorientation

Anonymous submission · ICRA 2027

Interactive CADSimulation videosSource code

A seven-axis robot can realize a six-dimensional end-effector pose, yet reorienting a contact tool may still require large motions of its long links. RuggedizedWrist adds two compact rotational axes at the tool. The simulations below compare the original 7-DoF arm with the 9-DoF system under the same operational-space pose and 15 N surface-normal force objectives.

Paired simulation recording

Near-to-far longitudinal scan

The corrected-mount run scans 160 mm from the near to the far torso point, applies a −35° tilt and return, then rotates 90° about the probe axis. The active wrist reduces J1–J7 reorientation travel by 68.82% while both systems remain below the supplementary 5° orientation reference.

160 mm scan · −35° tilt and return · axial 90°

Paired simulation recording

Cross-waist lateral scan

The corrected-mount run traverses 144 mm across the waist, applies a +30° tilt and return, then rotates 90° about the probe axis. J1–J7 reorientation travel falls by 84.58%; the active run exceeds the supplementary 5° orientation reference, so that limitation is reported with the result.
