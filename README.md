# RuggedizedWrist anonymous artifact site

This repository contains the static project page for **RuggedizedWrist**, a two-axis distal wrist evaluated in contact-rich reorientation and matched-start dynamics studies.

The page is prepared for anonymous ICRA review. It intentionally omits author names, affiliations, laboratory references, and personal links. It includes the original interactive URDF viewer, synchronized 7-DoF/9-DoF recordings, mount-configuration comparisons, CARE coverage panels, S2/S3 dynamics, and representative contact traces.

## Deployment

GitHub Pages serves the site at [ruggedizedwrist.github.io](https://ruggedizedwrist.github.io/) from the `main` branch. The custom-domain mapping is stored in [`CNAME`](CNAME).

## Evidence

Curated claim definitions and limitations are available in [`docs/evidence/`](docs/evidence/). The site is buildless: edit the static HTML/CSS/assets, then commit and push to `main`.
